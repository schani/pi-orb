# 2026-08-05 — GitHub App installation is a separate, mandatory step

Status: understood; no code change required. The GitHub credential design is in `docs/credentials.md`.

**Operational finding (2026-08-05): installation is a separate, mandatory step, and its absence is easy to misread.** Registering the app and completing the device ceremony are not enough — the user-to-server token's effective permissions are the intersection of the user's access, the app's permissions *as granted on an installation*, and the installation's repository selection. With no installation the token still reads public repositories fine (and `GET /repos/{owner}/{repo}` still reports the *user's* `push`/`admin` relationship), so everything looks healthy until the first write fails with `403 Resource not accessible by integration`. The same signature appears when the repo is outside the installation's selection or when a post-install permission upgrade is still pending approval on github.com/settings/installations. Installing (or approving) takes effect immediately — u2s tokens are evaluated against installations at request time, and the `gh` shim fetches a fresh token per invocation, so no orb restart or re-login is needed.
