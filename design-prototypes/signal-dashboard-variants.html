Signal: orb screen and three dashboards

The first frame is the orb screen. The next three are dashboard variants; each frame opens on its dashboard, and its Orb tab shows the same orb screen. All frames scroll independently.

Orb

Signal with the requested orb changes: index shows only the current project's working set, no app bar or find, no image or terminal buttons, terminal minimise-only, state hues on glyphs and row borders, user turns as grey bands.

Dashboard A · Ledger

One table, one line per orb. Fixed columns page-wide: glyph, name, state, note, age, actions. Projects are group-header rows. Archive is a collapsed row per project. New Project is a single inline row.

Dashboard B · Boards

Projects as side-by-side columns. Two-line orb entries with a state-coloured left border. Archive is a column footer. New Project is the last column.

Dashboard C · Attention

Organised by what to look at, across projects: Needs you, Working, then Projects with counts and actions. Project is a tag on each row rather than a group.
