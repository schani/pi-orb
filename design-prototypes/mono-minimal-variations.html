Mono-minimal, five variations

Base first, then five variations that change typography, colour, or both. Layout and content are identical across all six. Each frame has its own Dashboard / Orb switcher and scrolls independently.

Base

Cleaned mono-minimal: right panes, key hints, breadcrumb and repeated brand removed. Lifecycle facts folded into one meta line under the orb header. JetBrains Mono 13px, no colour.

1 · Plex duo

Typography only. IBM Plex Sans 14px for prose and names, IBM Plex Mono 13px for everything structural or literal. Still no colour.

2 · Signal

Colour only. Two hues as signals: green for what is alive now, red for what failed. Diff metrics coloured. Type unchanged.

3 · Inter states

Inter throughout, mono only for code. Each lifecycle state gets a muted hue on its glyph and a 2px left border. Nothing else coloured.

4 · Serif attention

Chrome stays mono. Conversation set in Source Serif 4 at 15px. One ochre hue means "needs you": auth banner, idle-waiting orbs, queued turn, abort.

5 · Ledger

Plex Sans Condensed chrome, Plex Sans prose, mono code. Pale record tints convey record type: user, shell, queued, compaction, auth. Diff and exit-code hues.
