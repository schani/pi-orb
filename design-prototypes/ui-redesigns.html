Ten complete UI redesigns

Each frame is a self-contained build of both main screens: the dashboard and an orb's chat. Use the Dashboard / Orb switcher at the top of every frame. Every frame scrolls independently; the buttons on the right resize it.

01

Eco-modern

Sage, clay, sand. Humanist sans plus a soft serif. Left sidebar rail, wide orb rows, comfortable reading column.

02

Plasti-tastic

Glossy Aqua-era candy plastic. Rounded bold sans. Capsule tab bar, glossy project trays, alternating chat bubbles.

03

Pixie-notes

Sticky notes on a corkboard and a ruled notebook page. Handwriting for user turns, typewriter for code.

04

Brick-swift

Toy-brick neo-brutalism in red, yellow, cobalt, black. Bento grid dashboard, stacked-brick transcript.

05

Eros-shock

Dark editorial: plum, crimson, rose. Didone display type. Magazine spread and pull-quote transcript.

06

Cyber-fun

Neon arcade HUD on navy. Pixel labels, techno names, VT323 body. Cockpit dashboard, split console chat.

07

Liquid-fart

Toxic-lime goo. Chunky rounded type, morphing blobs, drippy dividers. Floating blob clusters, gooey bubble stream.

08

Cloud-jizz

Milky pearl sky with lilac and peach. Light geometric sans, glassmorphism. Drifting islands, airy floating cards.

09

Mono-minimal

Black, white, three greys, one monospace at 13px. Three-pane multiplexer, glyph-only state, tabular everything.

10

Color-minimal

Flat Swiss: one grotesk, one solid color per lifecycle state as large fields. Split screen with a color state column.
