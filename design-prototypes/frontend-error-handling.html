Principled frontend recovery · five surface directions

An action never disappears
without an answer.

The failed message exposed a system-wide gap, not a composer-only bug. Every HTTP read, mutation, poll, live socket, and terminal connection can fail. The fix is one exhaustive failure model, with each request owner preserving intent and presenting recovery where that operation happened.

Implementation plan

One boundary, small state machines.

Keep the architecture first-party and explicit: no notification framework, query cache, or global exception-driven control flow.

01 · DetectNormalize at transport

Add a deadline and IAP’s AJAX signal to every API request. Classify auth challenge, offline/timeout, typed HTTP, malformed response, and cancellation.

02 · RouteScope by consequence

Session failures become app-wide state. Foreground mutations stay with their control. Reads own page-level states. Polling and sockets mark data stale.

03 · RecoverPreserve intent

Keep composer text and images until durable 202. Retry the exact message ID and body. Reauthenticate through a same-tab IAP round trip, then resynchronize and retry.

04 · ProveTest every edge

Fixture failpoints plus component and E2E tests cover expired auth during send, timeout ambiguity, malformed bodies, reconnects, retries, and render crashes.

Failures are typed facts

auth_required, offline, timeout, http, invalid_response, protocol, and unexpected. User copy is derived separately.

Uncertainty is explicit

A request may reach the server before the browser loses its response. Idempotent mutations retry with the same identity; non-idempotent work must reconcile before offering retry.

Visibility follows ownership

Foreground action errors are adjacent to that action. Session state persists globally. Background degradation uses a compact stale/reconnecting status, not repeated banners.

Complete request coverage

The transport adapter guarantees classification; the operation owner decides consequence and recovery. A generic global error queue cannot safely make that decision.
